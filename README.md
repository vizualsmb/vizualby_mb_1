# VIZUAL BY MB

A cinematic portfolio built with Next.js, TypeScript, GSAP, Framer Motion, and Resend.

## Local development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and configure the three Resend variables before testing email delivery. Without them, the form returns a clear configuration error.

## Editing content

- Projects: `data/projects.ts`
- Site details, social links, and services: `data/site.ts`
- Project media: `public/images/`
- Brand mark: `public/logo/mb-logo.png`

The current imagery and project copy are original placeholder concepts intended to be replaced with production work.
